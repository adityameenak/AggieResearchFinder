# UT Austin Faculty Directory Seeds
# One URL per line. Lines starting with # are ignored.
#
# Run:  python crawl.py --seeds seeds-ut.txt --university ut --output faculty-ut
#
# Unlike TAMU (one engineering domain) and Rice (one JSON:API), UT Austin
# spreads STEM faculty across per-department subdomains, each a separately
# themed site. The department is taken from the subdomain (see
# _UT_SUBDOMAIN_DEPT in crawl.py), and profiles are parsed by
# _extract_ut_profile(), which targets the shared "UT Drupal Kit" markup.
#
